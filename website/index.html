为什么选它

少打扰，把清单放在手边

不是再造一个复杂项目管理工具，只把日常待办、备注和提醒收干净。

一眼能看完

浅色侧栏、白卡片和状态胶囊，分组、置顶和收藏都在同一套界面里。

关窗口也还在

托盘常驻，关闭只是收起。提醒、全局快捷键继续有效，右键托盘才真正退出。

备注按 GitHub 风格显示

任务可写 Markdown。悬停预览，失焦才关；点开后左边编辑、右边实时渲染。

功能

日常会用到的那些

从拖拽排序到归档导出，覆盖清单本身，而不是一堆用不上的模块。

分组与总览

侧栏分组可收起、拉宽。收藏、归档和全部任务分开看，总览还能按状态筛选。

四种状态

待办、进行中、完成、已取消。左键在圆点上循环前三态，右键直接选取消，和完成一样沉底可归档。

拖拽排序

按住左侧手柄调整顺序。置顶区和普通任务各自排序，重要事项固定在顶部。

循环与提醒

循环任务每完成一次留下快照。也可以设一次性提醒，或按日 / 周 / 月 / 年周期回来。

归档与导出

每月 1 日自动归档上月已结束任务，也可手动归档。按月份查看，并导出 Excel。

本地优先，可选同步

数据默认在本机。需要的话指定云盘文件夹，启动时按最后修改时间合并。

快捷键与置顶

自定义添加任务、显示 / 隐藏窗口。可选开机自启和窗口置顶，清单不跑到后面。

高分屏友好

基于 Tauri 2，安装包小，界面按高分辨率屏幕收过一遍，4K 下也清楚。
