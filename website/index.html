功能特性

专为效率设计的每一个细节

从任务管理到 Markdown 备注，iamnote 覆盖日常工作的核心需求。

📁

分组管理

任务按分组组织，侧边栏可收起或拉宽，让信息层级一目了然。

🔄

三态任务状态

待办 → 进行中 → 已完成，左键正向切换，右键反向切换，操作直觉流畅。

📌

任务置顶

将重要任务固定在分组顶部，确保关键事项不被遗漏。

⭐

收藏视图

收藏任意任务，统一在收藏视图查看，修改双向同步，跨分组聚焦重点。

📝

Markdown 备注

每个任务支持 Markdown 备注，悬停预览，点击打开编辑浮窗，左侧编辑右侧实时渲染。

🗄️

自动归档

每月 1 日自动归档上月已完成任务，也可手动归档，按月份分类查看历史。

📤

导入 / 导出

一键将所有分组和任务导出为 JSON 文件，支持从备份恢复全部数据。

☁️

云端同步

指定本地云盘文件夹（Google Drive / OneDrive 等），启动时以最后修改时间自动合并数据。

⌨️

自定义快捷键

可自定义「添加任务」应用快捷键和「显示 / 隐藏窗口」全局快捷键，手不离键盘。

🚀

开机自启

可选开机自动启动，应用始终待命，随时记录灵感和任务。

📐

窗口置顶

可选始终显示在最前，任务清单不被其他窗口遮挡，专注不中断。

🖥️

4K 高分优化

UI 针对高分辨率屏幕专项优化，在 4K 显示器上依然清晰锐利。
